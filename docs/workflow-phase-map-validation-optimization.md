# 相位图校验、验证与优化通用流程

> **适用场景**：拿到**任意一张相位图**（SLM / DOE / 相位掩模 / CGH），需要判断它是什么、
> 它在你关心的距离上产生什么光场、能否更好，并给出可验证、可交付的结论。
>
> **最小输入**：相位图文件 + 波长 + 像素尺寸 + 重建距离。
> 有阵列尺寸、入射功率、照明形式更好；没有则先用名义值并在报告中显式标注为假设。

---

## 0　总体流程一页图

```
相位图 ──▶ ① 参数表化 ──▶ ② 图案辨识 ──▶ ③ 坐标/量纲规范 ──▶ ④ 传播模型
                                                                    │
        ⑧ 交付打包 ◀── ⑦ 四层验证 ◀── ⑥ 逆设计优化 ◀── ⑤ 指标定义 ◀┘
```

每一步的产物都可独立复核；**任何一步的"未经核对的假设"都是后续返工的来源**。

## ① 参数表化（把未知变成可核对清单）

先建一张表，逐项填写并标注来源（用户给定 / 图件标定 / 假设）：

| 类别 | 项目 | 说明 |
|---|---|---|
| 器件 | 阵列尺寸 N_x × N_y、像素间距 Δ | 决定物理口径（关键！） |
| 器件 | 相位编码约定 | 8 bit ↔ 0–2π 是 `I/255·2π` 还是 `I/256·2π`，影响 < 0.5 % |
| 光学 | 波长 λ、重建距离 z | — |
| 光学 | 入射场形式 | 平顶 / 高斯（w 或 D）、总功率 P、偏振（标量近似是否成立） |
| 报告 | 强度/功率/能量单位 | 统一为 mW/mm²、mW、nJ（或 J），**先定单位再算** |
| 假设 | 忽略项 | 吸收、反射、像差、装配误差、SLM 填充因子 |

**检查点**：阵列尺寸与像素间距必须来自同一口径定义。
若文件实际像素数与名义值不符（例如名义 512 × 512，文件 256 × 256），
物理口径按名义值处理，并在报告中写明"按 2× 降采样解读"——两种解读会给出完全不同的器件。

## ② 图案辨识（拟合，而不是猜）

### 方法

1. 由灰度重建复振幅 `E = exp(iφ)`；
2. 求**复振幅梯度**（而不是对包裹相位做差分/插值）：
   `gx = angle(E[:,1:] · conj(E[:,:-1]))`，`gy = angle(E[1:,:] · conj(E[:-1,:]))`
3. 转入极坐标分解：`g_r = gx·cosθ + gy·sinθ`，`g_θ = −gx·sinθ + gy·cosθ`
4. 在环形区域（避开核心 5–10 像素）内做线性最小二乘，拟合候选模型

### 常见模型库

| 结构 | 相位形式 | 辨识特征 |
|---|---|---|
| 锥透镜 axicon | `−k·sinα·r` | `g_r` 恒定、`g_θ` ≈ 0 |
| 螺旋相位 vortex | `ℓ·θ` | `g_θ ≈ ℓ/r`，中心环绕积分 = ℓ |
| 球面透镜 lens | `−k·r²/(2f)` | `g_r ∝ r` |
| 菲涅耳波带片 | `−k·r²/(2f)` 二值化 | 环带等宽，`g_r ∝ r` 分段常数 |
| 螺旋锥透镜（本类） | `−k·sinα·r + ℓ·θ` | `g_r` 恒定 **且** 环绕积分 = ℓ |
| 自由曲面 DOE | — | 拟合残差大，转 §⑥ 直接逆设计 |

### 判据

* 残差均方根 ≈ 量化步长/√12（8 bit 时 ≈ 0.007 rad）→ 该图是**量化后的理想器件**；
* 残差远大于量化噪声 → 依次排查：**坐标原点**（中心偏移半个像素都会造成线性残差）、
  灰度量程（是否只用了部分灰阶）、是否存在偏心/倾斜（残差呈线性斜坡）、是否存在像差（残差呈低阶多项式）。

**输出**：结构类型 + 参数（锥角、拓扑荷、焦距、偏心）+ 残差统计。

## ③ 坐标、量纲与相位编码的规范化

1. **不要直接对包裹相位插值。** 需要重采样 / 放大 / 延拓时，对复振幅 `exp(iφ)` 的实部虚部插值，
   或**按拟合出的公式直接生成**（更干净，且天然支持任意阵列尺寸）。
2. **一切"取中心区域"的代码都要显式声明坐标系。** 补零后的场中心 ≠ 原图中心，
   两者相差 `pad` 像素；这是最容易发生、最难自查的一类错误。
3. **校验重画/重采样正确性**：与输入图在重叠区做逐点相位差，
   差值均方根应回到量化极限（8 bit ≈ 0.007 rad）。
4. **量纲换算**（记入报告）：

```
平顶照明：I = P / A ，A = 阵列物理面积
高斯照明：I_peak = 2P / (π w²)      （w 为 1/e² 强度半径；有截断时按实际离散积分归一）
能量：   E = P · τ                  （τ 为脉宽或曝光时间；连续光只报功率与强度）
```

> 自检口诀：**先换算，再比较**。用归一化量做跨条件的图件比较，
> 会得到"看起来对、结论相反"的结果（本例中平顶与高斯的峰值强度关系就属于此类）。

## ④ 传播模型与网格

### 选型

| 方法 | 适用条件 | 备注 |
|---|---|---|
| 精确角谱（ASM） | `z ≤ N Δ²/λ` | 首选；结果最可信 |
| 带限角谱（Matsushima） | 任意 z | 大 z 时自动限带，避免传递函数混叠；限带截止需大于光束角谱 |
| 菲涅耳卷积（IR） | 观察窗 `L ≳ λz/Δ` | 保留像素尺度，适合近距离精细结构 |
| 菲涅耳单 FFT（缩放坐标） | 远场/大 z | 输出像素 `λz/(NΔ)`，适合看整体分布 |

### 三个必须当场核算的条件

1. 采样条件：`z ≤ N Δ²/λ`（不满足 → 加零填充或换带限法）；
2. 窗口 vs 外扩：衍射后光斑横向范围 + 边缘衍射余量应落在计算窗口内；
3. 带宽：光束角谱 `sinθ/λ` 必须落在带限截止频率以内。

### 一次交叉验证（只做一次，写进报告）

用两种独立方法算同一平面，比较**峰值强度、主瓣尺寸、环带能量**；
能量守恒应回到 1.0000（带限法通常 ≤ 0.05 % 偏差）。

## ⑤ 指标定义（先定义，再优化）

对任意相位图，建议统一采用以下四类指标：

| 类别 | 定义 | 说明 |
|---|---|---|
| 主瓣 | 由理论特征尺寸界定（如 Bessel 的第一零点 `0.61λ/sinα`、Airy 半径 `0.61λ/NA`） | 不要"看图划线"，否则优化会利用边界定义漏洞 |
| 旁瓣 | 以理论环间距/零点划分固定环带，取**环带内峰值 / 主瓣峰值**（dB） | 同时报环带功率（mW），因为 dB 高不代表功率大 |
| 效率 | 主瓣内能量 / 入射总能量（%），并换算 mW 与 nJ | 相位元件不吸收，效率提升等价于旁瓣能量转移 |
| 纵向 | 峰值、光斑尺寸、主瓣能量随 z 的曲线；无衍射结构的区间长度 | 决定"工作区间"，是后续优化的约束来源 |

**双路径校验**：同一指标用"直接像素求和"与"径向积分"两条路径各算一次。
两者不一致时优先怀疑分箱、插值与坐标系，而不是物理。

## ⑥ 逆设计优化（伴随梯度 + 多平面约束）

### 4.1 变量（参数化 = 制造约束）

| 参数化 | 何时使用 | 制造含义 |
|---|---|---|
| 径向对称相位 δ(r) | 圆对称目标（轴锥、环聚焦、Bessel） | 节点间距建议 = 1–2 个 SLM 像素 |
| Zernike / 多项式 | 需要低阶像差补偿 | 天然平滑 |
| 自由网格相位 | 目标非对称（多焦点、整形） | 需加平滑正则，避免像素级噪声解 |

### 4.2 目标函数（模板）

```
(a) 区域能量：   J = P_main / P_in = ∫_S I dr / ∫ I dr          # 等价于"把旁瓣功率搬进主瓣"
(b) 对比度：     J = ln(I_main) − ln(I_side)                    # 直接优化旁瓣 dB，不怕整体变暗
(c) 多平面：     J = Σ_j w_j · f(指标_j)                        # 迫使整个工作区间同时达标
(d) 稳健性：     J = min_k f(指标_k)  或  Σ_k w_k f_k，k 遍历扰动（束腰/偏心/波长/装配）
(e) 联合：       J = Σ_j w_j·ln(P_main,j) − λ·Σ_j ln(SL_j) − μ·‖平滑项‖
```

**目标函数设计的三个铁律**

1. 约束集必须**足够密**：只在少数平面上约束，优化器会造出"只在约束平面上成核"的伪解；
2. 不要让目标奖励"展宽"：以固定区域的能量为目标时，主瓣会被摊平以填满考核区，
   应改用"对比度"或"区域能量 + 峰值强度"的联合目标；
3. 每次改目标函数都要**重做梯度校验**（见 §4.4）。

### 4.3 伴随梯度（通用形式）

设 `J = Σ_j w_j · <χ_j U_j, U_j> / D_j`，`U_j = P_j E`，`E = A·exp(iφ)`：

```
∂J/∂φ(s) = Σ_j (2 w_j / D_j) · Im[ conj(E(s)) · P_j†( χ_j U_j )(s) ]
```

* `P_j†` = 反向传播（传递函数取共轭做一次 FFT/IFFT），与神经网络的反向传播同构；
* `Im[...]` 而非 `Re[...]`：相位元件只能"转动相量"，实部对应改振幅，物理上不可用；
* 一次正向 + 一次反向即可得到全像素梯度（本例 2×10⁶ 个分量）。

### 4.4 梯度校验（必做）

随机取方向 `v`，比较：

```
有限差分： [J(δ + h·v) − J(δ − h·v)] / (2h)
伴随预测： <∂J/∂δ, v>
```

偏差应 < 1 %（本例 0.00–0.04 %）。**没有通过这一步的优化结果一律不可信。**

### 4.5 优化器与停止准则

* Adam，学习率 0.03–0.05；加轻微平滑正则（二阶差分惩罚）抑制高频振荡；
* 监控"目标值 + 物理指标"双轨：目标值提升但主瓣尺寸异常增大 → 说明目标函数有漏洞；
* 收敛判据：连续若干轮相对提升 < 0.1 %。

## ⑦ 四层验证栈

| 层 | 验证内容 | 通过判据 |
|---|---|---|
| L1 数值 | 传播能量守恒、双方法交叉、梯度有限差分 | 能量 1.0000±0.05 %；指标差异 < 1 %；梯度偏差 < 1 % |
| L2 物理 | 峰值、尺寸、环间距与解析理论比较 | 偏差 < 5 %（超出须给出解释） |
| L3 鲁棒 | 照明口径 ±30 %、改平顶/高斯、±z 离焦 | 关键指标退化可量化，且不出现"只在设计点成立" |
| L4 制造 | 相位梯度 ≤ 奈奎斯特（`λ/2Δ`）、特征尺寸 ≥ 1–2 像素、相位连续、无奇点残留 | 全部通过才能下单加工 |

> 只有在 **L4 通过** 之后，"优化后旁瓣降低 X dB"才是可交付的结论。

## 附 A　常见失效模式与对策

| 失效模式 | 现象 | 对策 |
|---|---|---|
| 坐标系混用 | 截窗偏移，差值图出现规则条纹 | 显式声明坐标系；用输入图逐点差校验 |
| 包裹相位插值 | 重采样后出现伪环、强度起伏 | 对 `exp(iφ)` 插值或按公式重生成 |
| 稀疏约束伪解 | 只在少数 z 平面成核，平面之间发散 | 约束平面加密（间隔 ≲ 特征纵向尺度/5） |
| 目标奖励展宽 | 主瓣变宽、峰值下降但目标上升 | 改用对比度目标或加入峰值项 |
| 归一化/单位混乱 | 跨条件比较结论相反 | 先统一绝对单位（mW/mm²、mW、nJ） |
| 像素级"钻空子" | 优化结果含 1–2 像素周期结构 | 限制参数化尺度；加入平滑正则；核对奈奎斯特 |
| 把固有结构当缺陷 | 试图消除 Bessel 近旁瓣、Airy 环 | 先推导物理上限；区分"可优化"与"结构固有" |
| 绘图静默失败 | 图好看但色标/图注/单位错 | 渲染后采样验证 + 数字三处一致性检查 |

## 附 B　代码骨架（语言无关）

```python
# 1) 标定与图案生成
phi_in = load_gray(path)/255 * 2*pi
slope, ell, phi0, res = fit_spiral_axicon(phi_in, dx)      # §②
phi_full = mod(-k*sin(alpha)*R + ell*TH + phi0, 2*pi)       # §③ 直接生成

# 2) 传播（带限角谱）
def propagate(E, z): return ifft2(fft2(pad(E)) * H_bandlimited(z))[:N,:N]

# 3) 指标
I = |propagate(E, z)|^2
P_main = sum(I * mask_main);  SL = 10*log10(max(I*mask_ring)/max(I*mask_main))

# 4) 逆设计（伴随梯度）
for it in range(iters):
    U = propagate(E, z);  I = |U|^2
    J = sum(chi*I)/sum(I)
    g = backpropagate(chi*U/sum(I))          # P†
    grad = 2*imag(conj(E)*g)                 # ∂J/∂φ
    param = project_to_nodes(grad)           # 像素梯度 → 参数梯度
    param = adam_step(param, lr)
    if it % 20 == 0: assert finite_difference_check()   # §4.4

# 5) 四层验证与交付
assert |E_out_energy/E_in_energy - 1| < 5e-4
save_phase_png(phi_opt); write_report(metrics, figures)
```
