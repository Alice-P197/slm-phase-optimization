# SLM 相位图重画与 100 mm 光斑旁瓣抑制

对一张 256 × 256、像素间距 8 µm 的螺旋锥透镜（spiral axicon，拓扑荷 ℓ = +1）相位图，
按公式重画为铺满 1920 × 1080 SLM 的完整相位图（像素间距仍为 8 µm），
计算并分析 z = 100 mm 处的光斑，随后用伴随梯度优化抑制旁瓣，
并给出优化后的相位图、光斑结果与完整计算代码。

## 主要参数

| 项目 | 取值 |
|---|---|
| 波长 | 1064 nm |
| SLM | 1920 × 1080，像素 8 µm（有效区 15.36 mm × 8.64 mm） |
| 通光口径 | 15.36 mm × 8.64 mm（图案铺满整幅 SLM） |
| 等效锥角 | α = 1.0000°（sinα = 0.017452，由输入相位图标定） |
| 环带周期 | 30.48 µm（7.62 个像素） |
| 贝塞尔光斑特征尺寸 | 亮环 17.87 µm，第一零点 37.18 µm，环间距 30.48 µm |
| 照明条件 | 平顶（单位振幅平面波）与高斯光束（1/e² 强度直径 5 mm，w = 2.5 mm） |
| 重建距离 | z = 100 mm |
| 传播模型 | 标量衍射，带限角谱法（Matsushima），网格 2048 × 1208 |

## 优化方法

- **优化变量**：径向对称的相位修正 δ(r)，节点间隔 1 个 SLM 像素（8 µm），共 1103 个节点，线性插值。
  相位形式 φ(r,θ) = −k·sinα·r + ℓ·θ + δ(r)，螺旋项 ℓ = +1 保持不变。
- **目标函数**：z = 100 mm 处主瓣（r < 37.2 µm）内的能量占比
  J = ∫<sub>r<37.2 µm</sub> I dr ⁄ ∫ I dr。相位元件不吸收能量，最大化 J 等价于将旁瓣能量转移至主瓣。
- **梯度**：伴随法解析求解，∂J/∂φ(s) = (2/D)·Im[E*(s)·P†(χU)(s)]，
  其中 χ 为主瓣掩模，P† 为反向传播算子；像素梯度经节点插值矩阵映射至 1103 个节点。
  实现正确性以有限差分校验，偏差 < 0.01%。
- **优化器**：Adam，学习率 0.05，迭代 200 次。

优化后相位的局部等效锥角随半径近似线性增长（r = 4.2 mm 处为 40×10⁻³），
与环聚焦关系 sinθ = (r − r₀)/z 的预测值 42×10⁻³ 相符：
均匀锥面波被改写为径向变化的锥角分布，使整个孔径的光线汇聚到半径 r₀ ≈ 13 µm 的圆环上。

## 复现

依赖：Python 3.9+，numpy、Pillow（绘图为标准库之外的唯一依赖）。

```bash
cd code
python run_gauss.py          # 重画相位图、基线计算、优化、优化后验证
python run_report_gauss.py   # 生成 HTML 报告与全部图表
```

`run_gauss.py` 中的可调参数：`W_MAIN`（高斯束腰）、`ITERS`、`LR`、`NODE_STEP`、`Z`（重建距离）。

## 说明

- 优化针对单一重建距离 z = 100 mm 进行，此时光斑旁瓣最低；其他距离处光斑形态与优化前接近。
- 优化相位对入射束腰变化（±30%）不敏感，但对平顶照明效果明显退化，
  使用时需保证照明为高斯光束且束腰与设计值接近。
- 计算采用标量衍射模型，忽略偏振与吸收。
